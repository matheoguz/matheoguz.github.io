Configuration du Paiement Stripe

⏱ ~45 min 0/9 taches
  • Creer un compte Stripe sur stripe.com
  • Verifier votre identite (carte d'identite / passeport)
  • Ajouter votre compte bancaire (IBAN)
  • Recuperer vos cles API : Dashboard > Developers > API Keys
  • Copier la "Cle publiable" (pk_live_...)
  • Ouvrir le fichier shop/js/stripe-integration.js
  • Remplacer 'pk_test_VOTRE_CLE_ICI' par votre cle publiable
  • Creer vos produits dans le Dashboard Stripe (nom, prix, image)
  • Tester un paiement en mode test avant de passer en production

🔑 Comment recuperer vos cles API

  1. Connectez-vous a dashboard.stripe.com
  2. Allez dans Developers (menu de gauche)
  3. Cliquez sur API Keys
  4. Copiez la Publishable key (commence par pk_live_)
  5. Gardez la Secret key en securite (ne la mettez JAMAIS cote client)

⚠️ Mode Test vs Production

Utilisez d'abord les cles pk_test_ pour tester. Une fois pret, basculez vers les cles pk_live_. Le bouton "Test mode" dans le Dashboard Stripe permet de basculer.

// Dans shop/js/stripe-integration.js // Remplacez cette ligne : const stripe = Stripe('pk_test_VOTRE_CLE_ICI'); // Par votre cle publiable : const stripe = Stripe('pk_live_xxxxxxxxxxxxxxxx');

Configuration AliExpress / Fournisseurs

⏱ ~1h30 0/6 taches
  • Creer un compte sur AliExpress
  • Rechercher les fournisseurs pour chaque produit du catalogue
  • Verifier les evaluations (minimum 4.5 etoiles, +1000 ventes)
  • Commander un echantillon de chaque produit pour verifier la qualite
  • Negocier les prix avec les fournisseurs (remise volume)
  • Sauvegarder les liens des produits fournisseurs dans un document

📦 Workflow de commande (a chaque vente)

  1. Le client commande sur HomeVibe → vous recevez un email Stripe
  2. Ouvrez le Dashboard Admin → voyez la nouvelle commande
  3. Allez sur AliExpress → commandez le produit correspondant
  4. Entrez l'adresse du client comme adresse de livraison
  5. Payez avec votre carte (le prix AliExpress = votre cout)
  6. Copiez le numero de suivi (tracking)
  7. Mettez a jour le statut dans le Dashboard Admin
  8. Envoyez le tracking au client par email

💡 Conseils fournisseurs

  • Privilegiez les fournisseurs avec l'option ePacket ou AliExpress Standard Shipping (livraison 10-20 jours)
  • Envoyez un message au fournisseur avant de commander pour verifier le stock
  • Demandez des photos reelles du produit (pas seulement les images marketing)
  • Comparez au moins 3 fournisseurs pour chaque produit

Pages Legales

⏱ ~30 min 0/4 taches
  • Remplir les Mentions Legales (shop/legal/mentions-legales.html)
  • Obtenir un numero SIRET (auto-entrepreneur ou societe)
  • Completer les informations dans toutes les pages legales
  • Verifier les CGV (Conditions Generales de Vente)

📜 Documents obligatoires pour le e-commerce en France

  • Mentions legales : nom, adresse, SIRET, email, hebergeur
  • CGV : prix, livraison, retours, droit de retractation (14 jours)
  • Politique de confidentialite : RGPD, cookies, donnees collectees
  • Politique de cookies : bandeau de consentement

⚠️ Important

L'absence de mentions legales est passible d'une amende de 75 000 EUR pour une personne physique. Assurez-vous que toutes les informations sont correctes et a jour.

Gestion Financiere

⏱ ~30 min 0/3 taches
  • Ouvrir un compte bancaire dedie a l'activite
  • Configurer les virements Stripe vers ce compte
  • Creer un tableur de suivi financier (ou utiliser le calculateur)

📈 Calcul de la marge

  • Recettes = Prix de vente x nombre de ventes
  • Depenses = Cout AliExpress + Frais Stripe (1.4% + 0,25 EUR) + Budget pub
  • Marge = Recettes - Depenses
  • Objectif de marge : 60-70%

💰 Frais Stripe

Stripe preleve 1.4% + 0,25 EUR par transaction reussie (cartes europeennes). Pour une vente a 29,99 EUR, Stripe prend 0,67 EUR. Integrez toujours ces frais dans votre calcul de prix.
